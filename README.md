# Student Progress Tracker

A small, browser-based dashboard for recording student exam results and following score trends. It uses plain HTML, CSS, and JavaScript, so there is no build step or package installation.

## Run it

Open `index.html` in a modern browser. Add students, then record each exam result with its subject, date, score, and maximum score. The dashboard updates immediately and shows each student's results over time.

## Data and averages

- Student and exam records are stored in this browser's local storage on this device.
- Each result is shown as a percentage so exams with different maximum scores can be compared.
- The class average is the arithmetic mean of all recorded result percentages.
- Use the same browser and device to see the saved data. Clearing browser storage removes it.

This starter is intended for local use. It does not include user accounts, cloud sync, or backups; avoid entering sensitive personal information.
